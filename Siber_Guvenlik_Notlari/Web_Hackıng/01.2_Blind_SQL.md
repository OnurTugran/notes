### Blind SQL Nedir?
Blind (Kör) SQL Injection, uygulamada bir SQL açığı bulunmasına rağmen, çalıştırılan sorgu sonuçlarının veya veritabanı hatalarının frontend'e (web sayfasına) yansıtılmadığı durumlara denir. Ekranda doğrudan veri okunamadığı için `UNION` gibi klasik saldırı teknikleri burada işe yaramaz. Ancak, sunucuya belirli mantıksal sorular sorarak veya yanıt sürelerini ölçerek farklı tekniklerle bu açıklardan yararlanmak hâlâ mümkündür.

### Koşullu Yanıtları Tetikleyerek Kör SQL Enjeksiyonundan Yararlanma (Boolean-Based)

**Kavram:**
Uygulama, veritabanı sorgusunun sonuçlarını veya hatalarını ekrana doğrudan yansıtmaz. Ancak sorgunun doğru (True) veya yanlış (False) dönmesine göre sayfanın davranışında ufak değişiklikler olur (örneğin "Welcome back" mesajının görünmesi veya kaybolması). Bu davranış farkı, veritabanına "Evet/Hayır" soruları sorarak veri çekmek için bir indikatör olarak kullanılır.

**Örnek Senaryo:**
Uygulama, kullanıcıları tanımak için bir Tracking (Takip) çerezi kullanıyor:
```text
Cookie: TrackingId=u5YD3PapBcR4lN3e7Tj4
```

Arka planda çalışan zafiyetli SQL sorgusu:
```sql
SELECT TrackingId FROM TrackedUsers WHERE TrackingId = 'u5YD3PapBcR4lN3e7Tj4'
```
*(Eğer çerez veritabanında bulunursa, sayfa "Welcome back" mesajı döndürüyor.)*

**Sömürü (Exploit) Mantığı:**
*   **Normal İstek (True):** `TrackingId=xyz123` -> Sonuç: "Welcome back" yazar.
*   **Zafiyet Testi (True):** `TrackingId=xyz123' AND 1=1--` -> Sonuç: "Welcome back" yazar.
*   **Kör Noktayı Doğrulama (False):** `TrackingId=xyz123' AND 1=2--` -> Sonuç: "Welcome back" YAZMAZ.

**Karakter Karakter Veri Çekme (Binary Search)**
`Users` adında bir tablo olduğunu ve `Administrator` kullanıcısının şifresini bulmaya çalıştığımızı varsayalım. Şifreyi bulmak için "Welcome back" mesajını bir Evet/Hayır mekanizması gibi kullanarak harfleri tek tek tespit ederiz:

**Adım 1: Havuzu Yarıya Bölmek**
```sql
xyz' AND SUBSTRING((SELECT Password FROM Users WHERE Username = 'Administrator'), 1, 1) > 'm
```
Eğer sayfa "Welcome back" mesajı döndürürse (True), anlarız ki şifrenin ilk harfi 'm'den büyüktür.

**Adım 2: İhtimali Daraltmak**
```sql
xyz' AND SUBSTRING((SELECT Password FROM Users WHERE Username = 'Administrator'), 1, 1) > 't
```
Eğer sayfa "Welcome back" mesajı döndürmezse (False), anlarız ki ilk harf 't'den büyük değildir (Harf m ile t arasındadır).

**Adım 3: Nokta Atışı Doğrulama**
```sql
xyz' AND SUBSTRING((SELECT Password FROM Users WHERE Username = 'Administrator'), 1, 1) = 's
```
"Welcome back" mesajı döndüğünde (True), şifrenin ilk harfinin kesinlikle 's' olduğunu doğrulamış oluruz.

Bu işlem, `SUBSTRING` fonksiyonundaki parametre değeri (1,1'den 2,1'e vb.) artırılarak şifrenin tamamı bulunana kadar devam eder.

> [!note] Önemli Not
> `SUBSTRING` fonksiyonu bazı veritabanı mimarilerinde `SUBSTR` olarak kullanılır.
